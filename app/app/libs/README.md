# Third-Party Library Notice: Nothing Glyph Matrix SDK

This directory contains `glyph-matrix-sdk-2.0.aar`, the official Nothing Glyph Matrix SDK library for Android (`com.nothing.ketchum:glyph-matrix-sdk`).

## Licensing & Terms of Use
- The Glyph Matrix SDK is proprietary software developed and owned by **Nothing Technology Limited**.
- Its use is governed by Nothing's Developer Terms and License Agreements.
- This repository bundles the binary AAR solely to facilitate reproducible source builds for the "Anything but a Game Controller" submission.

## Obtaining the Official SDK
The SDK, documentation, and sample applications can be obtained directly from Nothing:
- **Developer Portal:** [Nothing Developer Portal](https://developer.nothing.tech)
- **Official GitHub Repository:** [Nothing Developer Programme on GitHub](https://github.com/Nothing-Developer-Programme) (e.g., `Nothing-Developer-Programme/Glyph-Matrix-SDK`)

For devices without Nothing Glyph Matrix hardware (e.g. Pixel, Samsung, OnePlus), Tiltmaze includes graceful runtime fallbacks that operate safely without making any SDK calls.
