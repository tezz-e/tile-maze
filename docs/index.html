4-Step Setup & Play
01 // INSTALL
Install Controller APK
Download tiltmaze-v1.0.0.apk from Releases and install on any phone running Android 8.0+.
02 // HOST
Run Relay on Laptop
Run npm start on your computer. The game and relay server launch together on port 3000.
03 // PAIR
Scan Lobby QR Code
Tap [ SCAN LAPTOP QR CODE ] in the app to pair in under 1 second via Google Code Scanner.
04 // TILT
Zero IMU & Steer
Tap [ CALIBRATE ] for neutral posture, tilt to steer the marble, shake to jump, and hold NITRO!
ARCHITECTURAL NOTE: The web game requires the local low-latency Node.js WebSocket relay server to receive live 60Hz binary IMU frames from the physical phone. The game is not playable standalone on this static page without running the local server.
System Architecture

20-Byte Binary Protocol

Orientation, button states, sequence counters, and client timestamps packed into 20 bytes with zero GC allocations.

Rotated Gravity Physics

Rapier 3D simulation dynamically rotates the gravity vector with continuous collision detection (CCD) for marble physics.

Adaptive 1€ Filtering

Filters hand micro-tremors at rest while eliminating phase lag during quick physical tilt flicks.

Nothing Phone (3) Glyph Matrix

Drives the 489 physical circular LEDs with sub-pixel Gaussian blobs and a dedicated 30Hz render thread.
